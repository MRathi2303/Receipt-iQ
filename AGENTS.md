# ReceiptIQ agent instructions

These instructions apply to every AI coding tool working in this repository.
Read [`AI-CONTEXT.md`](AI-CONTEXT.md) and [`WORKLOG.md`](WORKLOG.md) before
starting.

## Mandatory completion rule

Before every AI run ends, update [`WORKLOG.md`](WORKLOG.md) with:

- date and tool/session
- user request
- files changed or reviewed
- validation commands and results
- remaining work or blockers

Update [`AI-CONTEXT.md`](AI-CONTEXT.md) when architecture, commands, AWS
configuration, product decisions, or known limitations change. If the tool
cannot write these files, it must report that limitation and must not claim the
work is complete.

## Project constraints

- Do not reintroduce SNS, SES, email verification, or email notifications.
- Do not add Terraform or automatic AWS provisioning unless the user explicitly
  requests it. AWS resources are intentionally configured manually.
- Never commit credentials, API keys, `.env` files, generated bytecode, or
  customer receipt data.
- Preserve the deterministic OCR/parser fallback when changing AI integration.
- Run focused tests and syntax checks for changed code before finishing.
- Use [`docs/AWS-MANUAL-SETUP.md`](docs/AWS-MANUAL-SETUP.md) as the source of
  truth for AWS resource names, policies, and wiring.
